Q2)Write a program to implement the Backward Chaining inference mechanism
Facts = {“A”, “B”} 
Rules = { “C”: [“A”, “B”],
 “D”: [“C”], 
“E”: [“D”] 
} 
Def backward_chaining(goal): 
If goal in facts: 
Return True 
If goal in rules:
Return all(backward_chaining(fact) for fact in rules[goal]) 
Return False 
Goal = “E” 
If backward_chaining(goal): 
Print(“Goal”, goal, “can be proved.”) 
Else: 
Print(“Goal”, goal, “cannot be proved.”)
